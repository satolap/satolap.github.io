FAQ

Short answers to the questions adopting teams ask most, each taken from the release README and policies.

Which Terraform provider do the modules use?

The official microsoft/msgraph provider. The modules add typed inputs, request shaping, documentation and tests on top of its generic msgraph_resource.

Which Terraform version do I need?

Every verified module requires Terraform {{TF_MIN}} or later, and {{PROVIDER_LINE}}. The Requirements section on each module page states its own Terraform and provider constraints.

Can I use beta modules in production?

Beta modules carry Microsoft's preview status: the underlying APIs can change without notice. Prefer v1.0 modules where they exist, pin versions, and read each release's interface changes before upgrading.

Does a first terraform init download everything?

Yes. Terraform downloads the whole catalog once for every module block, even though each block uses one directory. Pin a version so that download happens once.

Can I consume the modules from GitHub instead of the Registry?

Yes. Use a Git source pinned to a release tag, for example git::https://github.com/satolap/terraform-msgraph-modules.git//v1.0/<graph-route>?ref={{TAG}}.

Which permissions do I need?

Verified module READMEs document the permissions they need. Generated module READMEs link to Microsoft's API documentation, which lists the permissions for each operation. Grant only what the modules you use require.

What does "verified live-accepted" mean on a module page?

The module's README records a live tenant run that was accepted on the stated date and commit. "verified offline-only" means the module passed the offline checks (validation and mock tests) and has no recorded live run. The README's Assurance line is the source.

Is there a support commitment?

Support is public and community-based: GitHub issues for problems and module requests, and private vulnerability reporting with an acknowledgement within seven days. The repository states no other support commitment. See support and policies.
