# satolap.github.io

Source of https://satolap.github.io, the product site for [terraform-msgraph-modules](https://github.com/satolap/terraform-msgraph-modules): versioned Terraform modules for Microsoft Graph on the official `microsoft/msgraph` provider.

Static HTML and CSS, no build step and no third-party scripts. Facts on the site come from the public repository, its releases and the Terraform Registry listing.
